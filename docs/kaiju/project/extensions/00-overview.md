# Overview

These are the records a piece of DeepScope work keeps. Fill them from current source and the requested journey. Remove
irrelevant rows with a reason. Keep secret references, never secret values.

DeepScope keeps them in the plan under `docs/migration/` that owns the work: the `## Active task` section is the
[active task record](../../agents/00-overview.md), and the other records are sections or tables in the same plan. Scratch
evidence (probe output, result files) goes in `.tmp/`, which Git ignores. After interruption, follow
[AE07](../../agents/07-ae07-preserve-work-and-resume-from-current.md) before running a new command.

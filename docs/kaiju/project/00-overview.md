# Overview

Copy this template for a new project. Fill it from current source and the requested journey. Remove irrelevant rows with
an explicit reason. Keep secret references, never secret values. These records are documentation templates; no existing
repository is claimed to parse them automatically.

Use the [active task record](../agents/00-overview.md) for decisions and continuation during long work. Link these
project records from it rather than maintaining duplicate copies. After interruption, follow
[AE07](../agents/06-ae06-retry-at-the-smallest-valid-scope.md) before issuing a new command.

# Overview

Use the relevant fields in the existing project or task record. Fill them from current source, the customer problem,
questions and requested journey. Do not create a separate document for every template. Remove irrelevant rows with an
explicit reason. Keep secret references, never secret values. These records are documentation templates; no existing
repository is claimed to parse them automatically.

Use the [active task record](../agents/00-overview.md) for decisions and continuation during long work. Link these
project records from it rather than maintaining duplicate copies. After interruption, follow
[AE07](../agents/07-ae07-preserve-work-and-resume-from-current.md) before issuing a new command.

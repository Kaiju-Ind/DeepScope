# Product questions, experiments and anchors

Use this entry for every task, including a skill invoked directly. Begin with the customer outcome and the decision
that evidence must support. Use the smallest credible experiment to establish an anchor that the team can act on.

Skills: `plan-changes`, `explore-ecosystems`, `benchmark-code`, `verify-behavior`, `review-code`, `write-docs`.

# Data, private networking and initialization

These failures cross application and platform ownership. Use P02 with the
[Kubernetes, KubeBlocks, registry and network contracts](../services/README.md), and P05 before retrying a partial
initialization.

| Entry                                     | Symptom and cause confidence                                                                                                                                                                                                                                                                                                   | Repair and evidence                                                                                                                                                                                                                                                                                                              | Earlier prevention                                                                                                                                                                                                                                                                                                                                                                        |

| **OA-06** Installed database catalog      | **Source diagnosis:** imported PostgreSQL/Redis floors did not match the installed compatible catalog. The supplied [OpenATS P02/A02](retrospectives/04-openats-problem-classes.md) adds an agent admission: the PostgreSQL 17.12 floor had not been established as an application requirement before custom-image work began. | [b6a0da5](https://github.com/Kaiju-Ind/OpenATS/commit/b6a0da59df8c6d466f1fd3042a825692ed74f270) selects compatible installed service versions and retains Platform ownership of engine maintenance. The retrospective records removal of the unnecessary image work; this does not establish the current patch-security posture. | [AE03](../agents/02-ae02-prove-access-and-report-owner-actions-early.md), [P01](../procedures/01-p01-open-the-project-and-report-prerequisites.md)/[P02](../procedures/02-p02-verify-required-service-contracts.md): prove the requirement, then read ComponentDefinition, ComponentVersion and image mapping. Keep application compatibility and platform security maintenance distinct. |
| **OA-07** Data node placement             | **Recorded deployment cause:** pods could land on nodes without the required node-local mount, causing volume creation on Talos's read-only filesystem.                                                                                                                                                                        | [2687895](https://github.com/Kaiju-Ind/OpenATS/commit/268789586869496a89dd84f9182b8f98e47480ba) selects `kaiju.io/pool-data=true`.                                                                                                                                                                                               | [P02](../procedures/02-p02-verify-required-service-contracts.md): inspect StorageClass, binding, mounts, capacity and node eligibility together. A valid PVC schema is not storage readiness.                                                                                                                                                                                             |

Native engine syntax may differ from the operator API.                                                                                                                                                                                                      |
| **OA-09** Setup credential lifetime       | **Recorded lifecycle issue:** setup Jobs needed registry access after preview; an old job's token could not be reused indefinitely.                                                                                                                                                                                            | [0edf113](https://github.com/Kaiju-Ind/OpenATS/commit/0edf113eed1cf4a1886947d6dfdf493ea4cf6c6e) refreshes the owned pull Secret from the apply job's current token.                                                                                                                                                              | [P02](../procedures/02-p02-verify-required-service-contracts.md)/[P05](../procedures/05-p05-recover-a-failed-deployment.md): record scope, owner, expiry and refresh point. Keep ephemeral credentials out of saved evidence and verify Secret ownership before replacing it.                                                                                                             |
| **OA-10** Initialized empty stack         | **Source diagnosis:** initialization could set `lastUpdate` without update history, triggering inappropriate configuration restoration.                                                                                                                                                                                        | [b87f253](https://github.com/Kaiju-Ind/OpenATS/commit/b87f2535ebf02a5cb47cc83335902f9eded4143e) checks native history and resource count and preserves first-launch inputs.                                                                                                                                                      | [P02](../procedures/02-p02-verify-required-service-contracts.md)/[P05](../procedures/05-p05-recover-a-failed-deployment.md): distinguish absent, initialized-empty, metadata-only and partially applied state. Missing outputs do not prove no resources exist.                                                                                                           |

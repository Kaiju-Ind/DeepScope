# Close coverage with a rehearsal, not a claim

Before the next project, use the selected normal path and its actual command bindings. Assign the relevant P08 drills to
an owner. A second operator should complete the first useful journey and one applicable failure/recovery path without
undocumented author help. Record the guide version, candidate, environment, intervention count and elapsed time.

Automation gaps remain explicit: reusable early-readiness reports, isolated-preview lifecycle, candidate promotion
records, complete image admission and exact-action acceptance checks are not all implemented across the organization.
Reuse existing tested owners first. Add a shared capability only when its real consumers and contract justify it. The
goal is earlier detection and repeatable recovery; the documents alone cannot prevent every future error.

# Start from the symptom

| Symptom                                               | First checks                                                                                                                                | Catalogue entries                                                                                                                            |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| Private dependency or shared tooling returns 403      | Intended token, package/repository grant, every transitive private dependency, cold fetch under the CI identity.                            | IAP-04, IAP-16, OA-01                                                                                                                        |
| Native preparation works only in one workspace        | Declared runtime, generator support, authentic generated artifact, committed lock and test fixtures.                                        | IAP-01, IAP-02, OA-02, OA-03, OA-05                                                                                                          |
| Database stays pending or configuration is rejected   | Installed KubeBlocks version mapping, storage placement, eligible nodes, exact units and schema.                                            | OA-06, OA-07, OA-08                                                                                                                          |
| Hosted runner cannot reach the cluster or setup image | Runner network identity, current registry token, Secret ownership and token lifetime.                                                       | IAP-08, OA-09                                                                                                                                |
| Empty installation cannot retry                       | Native history, resource count, metadata-only state, pending operations and original configuration.                                         | IAP-09, OA-10, OA-21                                                                                                                         |
| Saved plan fails or a second preview is not empty     | Resource identity, unresolved outputs, explicit dependencies, provider normalization, refresh semantics and field ownership.                | IAP-10, IAP-11, IAP-12, OA-14, OA-16 through OA-20                                                                                           |
| Image exists but runtime or health checks fail        | Digest versus tag, selected architecture, entrypoint argument semantics, listener address and required worker.                              | IAP-13, IAP-14, IAP-19, OA-12, OA-13                                                                                                         |
| Selected image digest is absent                       | Authenticate with the intended pull identity, inspect the registry manifest and selected platform; distinguish absence from access refusal. | ItsAPlan retrospective P24 in [coverage](retrospectives/02-itsaplan-problem-classes.md); this differs from IAP-14's existing-but-wrong image |
| Invite says sent but no message arrives               | Which process sends it, actual runtime egress, sender/key scope, SMTP acceptance, provider event and inbox.                                 | OA-22, OA-23, OA-24, OA-27                                                                                                                   |
| Storage works in API but a migration fails            | Same endpoint, region and capabilities in every consumer; public/private bucket policy.                                                     | OA-26; storage safeguards below                                                                                                              |
| Provider advertises a feature but creation fails      | Actual account entitlement and live API response, not only a tier description.                                                              | OA-15                                                                                                                                        |
| AI works in one command but not the application       | Environment key, model/API dialect, actual consumer, retry owner and cancellation.                                                          | IAP-05, IAP-17; current gaps below                                                                                                           |
| User journey fails after green checks                 | Which result was proved: source, artifact, workload or user outcome.                                                                        | OA-24; product limits below                                                                                                                  |
| Workspace failure loses progress                      | Remotely verified commits, independent patches, exact ancestry, dirty-state archive.                                                        | IAP-18                                                                                                                                       |

# Keep the pack accessible

The persistent entry point is `/Guides/Kaiju Projects/00-READ-FIRST.md`. Code History's START-HERE document routes Kaiju
hosting work here. Search for **Kaiju project playbook** if the folder is not directly visible.

For Codex, copy the portable pack into a repository at `docs/kaiju/`. Merge the short routing section from
`AGENTS.fragment.md` into the existing root `AGENTS.md`. Confirm the files are present and ask Codex to identify its
active instructions. A Library save alone does not install instructions into Codex.

The handbook defines proposed common procedures and file ownership. The repository's verified command binding decides
what can actually run. Do not paste a proposed command into a workflow and assume that an implementation exists.

Version 1.1.0 incorporates Carl's two deployment retrospectives. The coverage map addresses all 85 original
problem/finding references, many of which overlap the original 46-entry source catalogue. The portable archive includes
the original reports with their recorded hashes. Preserve their historical evidence limits and scoped approvals when
using them.

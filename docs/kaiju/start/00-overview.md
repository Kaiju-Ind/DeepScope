# Overview

Use this pack when Carl says a project is a Kaiju project, asks to self-host an application, or asks to deploy it on
Kubernetes or Bunny. Start with a small usable outcome. Establish the services it needs, deliver a working preview, then
promote a verified candidate through a separate production procedure.

The deployment chapters come from Kaiju's deployment reviews and retrospectives, and the CI chapters from Core's CI
work. Neither proves a new project's live deployment or end-to-end CI implementation.

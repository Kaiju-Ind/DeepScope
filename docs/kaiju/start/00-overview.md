# Overview

Use this pack for product work in any organization: investigation, design, implementation, operations, documentation,
performance or delivery. Start with the user's desired outcome and the customer problem. Identify the unknowns that
could change the next decision, then run the smallest useful experiment before substantial implementation.

Read [A01](../product/01-a01-start-from-the-product-question.md), select the
[generic project profile](../profiles/generic.md), and follow the relevant skills. The
[Kaiju profile](../profiles/kaiju.md) is opt-in. The directory name preserves the playbook's history; it does not require
a particular company, language, package manager, cloud or deployment architecture.

The deployment chapters come from Kaiju reviews and retrospectives, and the CI chapters from Core's CI work. Their
source-specific observations are historical evidence. They do not prove a new project's live behavior. Use them where
the task shares their contracts, refresh the current facts, and keep the customer's acceptance result visible.

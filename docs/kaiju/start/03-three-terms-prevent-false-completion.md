# Three terms prevent false completion

**Passing checks** means types, tests and builds passed on a named commit. **Usable preview** means the built extension
was loaded in each target browser and the reviewer completed the agreed journey. **Release acceptance** means the
reviewed commit was tagged, its archives, checksums and attestations were published and verified, and each store
submission reached the intended state (uploaded, in review or published).

Each is separate evidence. A green Verify workflow does not show that the extension works in Safari. A built zip does
not show that a store accepts it. A store upload does not show that review passed.

# Overview

A DeepScope change should become usable in a real browser early. The repeatable unit is a small change with known
owners, a checked browser contract and a short path to a build that a reviewer loads. Releasing adds the checks that
protect existing users and what their browsers have stored.

This handbook keeps the principles of Kaiju's project handbook and replaces its server examples with DeepScope's.
Words such as **planned** identify structure or automation that does not exist yet. Measurements are evidence for the
change that recorded them, not permanent targets.

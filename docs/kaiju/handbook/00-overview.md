# Overview

A Kaiju project should become useful before deployment work consumes a day. The repeatable unit is a small application
integration with known owners, verified service contracts and a short path to a usable preview. Production promotion
adds the checks needed to protect existing users and data.

This handbook uses current ItsAPlan and OpenATS source and workflow evidence. Grafana, Twenty and shared tooling provide
additional ownership examples. Words such as **proposed** identify automation that does not yet exist. Exact versions
are evidence for this review, not permanent version recommendations.

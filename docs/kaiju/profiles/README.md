# Project profiles

The product method applies across organizations, products, languages and runtimes. Profiles bind that method to the
actual project. They do not create new authorization or make an example platform a requirement.

Skills: `plan-changes`.

| Profile | When it applies |
| --- | --- |
| [Generic project](generic.md) | Default for every project. Use current repository rules, verified commands and the requested customer outcome. |
| [Kaiju](kaiju.md) | Opt in when the current task or repository identifies the applicable Kaiju organization, packages and platform contracts. |

Record the selected profile in the existing project or task record. A profile is a set of applicable choices, not a
second mandatory document. Keep current user instructions and existing project rules authoritative. A `docs/kaiju/`
directory or the history of this playbook does not select the Kaiju profile by itself.

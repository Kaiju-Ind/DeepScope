# Task prompts

Prompts for product questions, experiments, progress updates, concrete plans and engineering tasks. Each prompt names
the skills to load and the playbook rules to follow, so a session started from it uses the same methods as the playbook. Copy one fenced prompt
into a new session and fill in the repository and branch. See [how to use them](00-overview.md).

Skills: `plan-changes`, `explore-ecosystems`, `build-devtools`, `benchmark-code`, `verify-behavior`, `deno-software`,
`test-code`, `review-code`, `build-libraries`, `release-software`, `refactor-code`, `use-kaiju-utils`, `write-docs`, `rust-software`.
